# 网络搜索代理（Tavily 兼容 REST 服务）

把 Key 池暴露为 **Tavily 官方 REST API 形态** 的本地/局域网代理服务，供
Cherry Studio 等 AI 客户端通过「自定义 API 地址」直接对接，无需把池内每个
Key 都填进客户端——所有请求由代理统一走 Key 池轮询、限流与异常切换。

## 对接方式（以 Cherry Studio 为例）

1. 启动本软件，打开面板 → 「**搜索代理**」页签。
2. 点击「启动服务」（或在下拉设置里开启「随软件启动搜索代理」）。
3. 复制 **API 地址**（本机用 `http://127.0.0.1:8002`；局域网设备用 IP/主机名地址）。
4. 在「API 密钥」处点击「**生成随机密钥**」并复制（也可手动填写）。
5. 在客户端设置中：
   - 网络搜索 → 选择 **Tavily** 提供商；
   - **API 地址** 填入上方的代理地址（如 `http://127.0.0.1:8002`）；
   - **API 密钥** 填入 `proxy_token`；
   - 点击「**检测**」应提示连接成功。
6. 对话中即可使用联网搜索，消耗与请求记录自动落入 Key 池（请求日志页可见）。

## 实现端点

| 端点 | 方法 | 说明 |
|---|---|---|
| `/search` | POST | 必填 `query`；支持官方全部 search 参数；**强制 `include_usage=true`** 保证本地积分落账 |
| `/extract` | POST | 必填 `urls`（单个 URL 或数组） |
| `/crawl` | POST | 必填 `url` |
| `/map` | POST | 必填 `url` |
| `/research` | POST | 提交 Research 任务（返回 `request_id`；参数白名单含 `output_length` / `output_schema` / `max_sources` / `max_subsources`） |
| `/research/{id}` | GET | 查询任务状态（跨进程共享 `research_keys.json` 固定同一 Key，避免 404） |

Cherry Studio 的 Tavily 提供商只调用 `/search`；`/extract` `/crawl` `/map`
`/research` 为兼容 Chatbox、NextChat 等其他客户端而实现。

> **不提供 `/usage`**：官方用量展示请使用面板统计页（内部对每个 Key 单独查官方
> `/usage` 聚合，走 `sync_usage`）；代理不转发 `/usage`，避免无意义地消耗
> Key 的 10 次/10 分钟用量查询预算。

## 鉴权

- 使用独立配置项 **`proxy_token`**（面板「搜索代理」页可一键生成）。
- 客户端通过 `Authorization: Bearer <proxy_token>` 请求头鉴权；也兼容把密钥放在
  JSON body 的 `api_key` 字段。
- **`proxy_token` 留空 = 不鉴权（对外开放）**——任何能访问该地址的设备都可消耗
  Key 池额度。面板在密钥为空时会显示风险提示；对外提供服务前请务必设置密钥。

## 管理与配置

- **配置项**（`data/config.json`）：
  - `proxy_auto_start`：软件启动时是否自动启动代理；
  - `proxy_host`：监听地址，默认 `0.0.0.0`（局域网可用），`127.0.0.1` 仅本机；
  - `proxy_port`：监听端口，默认 `8002`；
  - `proxy_token`：代理密钥。
- **配置热刷新（v0.7.0）**：代理每次请求按 TTL（1s）感知 `config.json` 变更——面板生成/修改 `proxy_token`、限流参数后**无需重启代理**即生效。
- **面板**：「搜索代理」页签展示运行状态、API 地址（局域网 IP / 主机名 / 本机，
  各带复制）、API 密钥（复制 + 生成随机密钥）与启停/设置。
- **API**：`GET /api/proxy/status`、`POST /api/proxy/start|stop`、
  `POST /api/proxy/token/generate`。
- **密钥安全（v0.7.0）**：`/api/proxy/status` 只返回**脱敏**密钥（前 4 后 4 位，
  附 `token_set` 标志），完整密钥仅由设置接口 `/api/settings` 提供——面板状态卡
  展示/复制时自动从设置接口读取，避免状态接口把密钥明文带出。
- **CLI**：`tavily-pool proxy` 展示运行状态、地址与密钥。

## 架构与实现

- `app/tavily_proxy.py`：FastAPI 代理本体（端点/鉴权/错误映射）。转发复用
  `mcp_server._run_with_retry`（Key 轮询、令牌桶限流、429 `retry-after`、额度/认证
  自动切换重试），因此请求自动计入 `request_log` 与各 Key 用量。
- `app/proxy_manager.py`：独立子进程管理（`--proxy` 角色），与 MCP 服务同构：
  端口探测、`netstat` 定位真实 PID、只清理本程序拉起的进程。
- 错误响应与官方一致：`{"detail": {"error": "..."}}`，状态码按类别映射
  （auth→401、quota→432、rate→429、池空→503、其他→500）。

## 注意事项

- **打包版**内置新前端（`web/dist`），升级前端后需重新 build 才生效。
- 代理与面板共享同一个 SQLite Key 池（多进程 WAL 并发安全，与 MCP 相同）。
- 代理日志：`data/proxy_server.log`。
